## Principes

1. Une caméra lisible, des formes simples, des animations expressives.
2. Garder les paramètres exposés tant que nous travaillons dans le gym.
3. Construire les séquences avec les outils de design du jeu.
4. Sauvegarder avant d’étendre la boucle.
5. Une proposition dans ce carnet n’est pas une mécanique approuvée ou implémentée.
